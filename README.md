# MyOnlineMeal
A responsive online food delivery website landing page built using HTML, CSS, and Media Queries.
## Features
- **Modern Landing Page:** Attractive food-themed banners and layouts.
- **Navigation Bar:** Fixed sticky navbar with smooth scrolling to sections (`Home`, `Services`, `Our Clients`, `Contact Us`).
- **Services Section:** Showcases offerings like Food Catering, Bulk Ordering, and Food Ordering.
- **Client & Partner Marquee:** Displays partner logos and delivery brands.
- **Responsive Design:** Custom mobile styling using media queries to ensure smooth viewing on smaller screens.
- **Contact Form:** Clean user feedback and inquiry form.
